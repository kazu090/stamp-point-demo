スタンプ型デジタルデバイス デモサイト（更新版）

【ローカルで見る】
このフォルダ内の index.html を Chrome / Edge で開いてください。
画像を正常に表示するため、HTMLと同じ場所の画像ファイルは移動しないでください。

【公開URLを作る】
1. https://app.netlify.com/drop を開きます。
2. 「フォルダを選ぶ」またはドラッグ＆ドロップを使います。
3. ZIPから解凍した、このフォルダの中身があるフォルダをアップロードします。
4. デプロイ完了後に発行される https://～.netlify.app/ のURLを共有します。

【注意】
・このサイトは操作デモです。実際のLINE連携やスタンプ記録は行いません。
・STEP 8・11のスタンプカードは添付画像をそのまま表示する固定画像で、設定した店舗名・枠数に合わせて画像内の内容は変わりません。
・公開されたURLは原則として誰でもアクセスできます。
